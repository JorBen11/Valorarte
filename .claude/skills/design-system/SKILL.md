# Skill: Design System de Valorarte

## Cuándo utilizarla

Utiliza esta skill cuando:

- Crees una pantalla.
- Modifiques componentes visuales.
- Añadas formularios, tarjetas o diálogos.
- Implementes un tema.
- Revises consistencia visual o accesibilidad.

## Documentación obligatoria

Antes de trabajar:

1. Lee `CLAUDE.md`.
2. Lee `docs/DESIGN-SYSTEM.md`.
3. Lee las secciones relevantes de `docs/SCREENS.md`.
4. Inspecciona los componentes visuales ya existentes.

## Procedimiento

1. Identifica el propósito de la pantalla y su acción principal.
2. Define la jerarquía de contenido.
3. Reutiliza componentes existentes cuando corresponda.
4. Utiliza tokens semánticos de color, tipografía y espaciado.
5. Comprueba los temas claro y oscuro.
6. Diseña estados de carga, error, vacío y éxito.
7. Comprueba textos largos, cantidades y valores monetarios.
8. Añade etiquetas accesibles a controles e iconos.
9. Evita duplicar estilos y componentes.
10. Revisa la pantalla en tamaños móviles razonables.

## Restricciones

- No introducir una paleta distinta sin autorización.
- No escribir colores arbitrarios en cada componente.
- No usar emojis como iconografía funcional.
- No añadir sombras, gradientes o animaciones decorativas innecesarias.
- No crear abstracciones reutilizables sin casos de uso claros.
- No usar tarjetas para todos los elementos indiscriminadamente.
- No reducir el tamaño del texto para ocultar problemas de diseño.
- No presentar datos de demostración como datos reales.

## Criterios de aceptación

La interfaz:

- Respeta el sistema de diseño.
- Tiene una jerarquía visual clara.
- Es legible en ambos temas.
- Mantiene consistencia con otras pantallas.
- Tiene estados de carga, error y vacío cuando corresponda.
- No depende solo del color para transmitir información.
- Tiene áreas táctiles adecuadas.
- Puede utilizarse con texto ampliado razonablemente.
